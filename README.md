# بين الشعور والقرار

نشاط تفاعلي لمقرر الذكاء العاطفي في جامعة طيبة.

## التجربة قبل النشر

فكّي ضغط الحزمة وافتحي `index.html` في متصفح حديث. اتركي الملف بجوار `styles.css` و`activity.js` ومجلد `assets`. تعمل المواقف والتغذية الراجعة والخلاصة محليًا، حتى دون اتصال. فتح رابط الفيديو الاختياري يتطلب اتصالًا.

## النشر عبر GitHub Pages

1. أنشئي مستودعًا عامًا جديدًا في GitHub، مثل `emotional-decisions`.
2. ارفعي محتويات الحزمة بعد فك الضغط إلى جذر الفرع `main`، مع الحفاظ على مجلد `assets`. يجب أن يظهر `index.html` مباشرةً في الجذر.
3. افتحي **Settings → Pages**. ضمن **Build and deployment** اختاري **Deploy from a branch** ثم `main` و`/(root)` واضغطي **Save**.
4. عند ظهور **Visit site** في إعدادات Pages، افتحي الموقع واختبريه. انسخي الرابط الظاهر وأضيفيه إلى زر في شريحة PowerPoint وإلى دردشة المحاضرة عند بدء النشاط.

[دليل إعداد مصدر النشر الرسمي](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

الموقع ثابت ولا يتطلب تسجيل دخول أو تثبيت حزم. يُعرض التقدم في الصفحة الحالية فقط، ويبدأ النشاط من جديد عند تحديثها. لا يرسل الموقع الاختيارات ولا يخزنها.

## العرض أثناء المحاضرة

- يظهر النشاط بنسبة 16:9 على الكمبيوتر وفي وضع الهاتف الأفقي عندما تسمح أبعاد الشاشة. في الهاتف العمودي، يظهر المحتوى عموديًا لتسهيل القراءة.
- اختاري زر **ملء الشاشة** من الترويسة. إذا تعذّر إخفاء واجهة المتصفح، يتوسع العرض داخل نافذته.
- الصوت مكتوم عند فتح الرابط. شغّليه أو اكتميه من زر **الصوت**.
- استخدمي زري **السابق** و**التالي** أو مفتاحي السهم الأيمن والأيسر. يظهر الانتقال إلى الموقف التالي بعد اختيار الإجابة والضغط على «اعتماد القرار»، ويمكن العودة لمراجعة القرار أو تغييره.
